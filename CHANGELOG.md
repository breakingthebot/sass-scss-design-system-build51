# Changelog

All notable changes to **Build 51 (ApexUI — Enterprise Sass/SCSS Design System)** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.0] - 2026-07-29

### Added
- Integrated **SCSS Multi-Theme Token Generator (`scss/abstracts/_themes.scss`)**.
- Added SCSS `$themes` nested maps and `@each` iteration loops generating `.theme-dark`, `.theme-light`, and `.theme-cyber` classes.
- Added pure CSS reactive theme switch radio buttons in top navigation bar.

## [1.0.0] - 2026-07-29

### Added
- Created **ApexUI — Enterprise Sass/SCSS Design System & Component Library** (Build 51).
- Implemented modular SCSS directory architecture (`abstracts`, `base`, `components`).
