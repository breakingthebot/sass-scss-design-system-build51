# Changelog

All notable changes to **Build 51 (ApexUI — Enterprise Sass/SCSS Design System)** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-29

### Added
- Created **ApexUI — Enterprise Sass/SCSS Design System & Component Library** (Build 51).
- Implemented modular SCSS directory architecture (`abstracts`, `base`, `components`).
- Added `$variables` for design tokens (Indigo/Slate palette, spacing scale, elevation shadows).
- Added `@mixin respond-to($breakpoint)` using modern Sass maps (`map.has-key`, `map.get`).
- Added real-world UI components: Metric Dashboard Widgets, Status Badges, Buttons, Enterprise Data Table, and Token Swatches.
- Compiled clean CSS `css/style.css` with zero JavaScript execution payload.
