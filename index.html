Modular SCSS Design System.

Build 51 implements a full-featured Sass/SCSS design system — utilizing `$variables`, `@mixins`, `@functions`, and nested components compiled into high-performance, clean CSS.

⚙️ View SCSS Modules 👥 Explore Character Bios
// scss/abstracts/_mixins.scss 
@mixin glass-card($bg: $color-card) {
  background: $bg;
  border: 1px solid $border-glow;
  backdrop-filter: blur(16px);
  box-shadow: $shadow-card;
}

@mixin respond-to($breakpoint) {
  @if map.has-key($breakpoints, $bp) {
    @media (max-width: map.get($breakpoints, $bp)) {
      @content;
    }
  }
}
🎨

`scss/abstracts/_variables.scss`

Houses all design tokens including `$color-cyan`, `$color-magenta`, `$font-heading`, `$font-body`, and `$breakpoints` map.

⚡

`scss/abstracts/_mixins.scss`

Provides responsive media query `@mixin respond-to`, `@mixin flex-center`, `@mixin grid-auto`, and `@mixin glass-card` utilities.

📦

`scss/components/*.scss`

Modular SCSS component stylesheets for navbar, buttons, hero, cards, polaroid table, radio visualizer, and dossier modals.
