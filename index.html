Enterprise SCSS Design System.

ApexUI is a modular, high-performance Sass design system engineered for enterprise UI teams. Built with structured `$variables`, `@mixins`, Sass map breakpoints, and zero runtime JavaScript dependencies.

// Responsive Breakpoint Helper
@mixin respond-to($breakpoint) {
  @if map.has-key($breakpoints, $breakpoint) {
    @media (max-width: map.get($breakpoints, $breakpoint)) {
      @content;
    }
  }
}

// Glassmorphism Container Mixin

  box-shadow: $shadow-xl;
}
SCSS FILE ARCHITECTURE

Structured for Scale

Divided cleanly into abstracts, base resets, and component-level stylesheets for effortless maintenance.

🎨

`scss/abstracts/`

Contains `_variables.scss` tokens, `@mixin respond-to` media queries, and `rem()` calculation functions.

Inspect Variables
⚡

`scss/base/`

Establishes typography hierarchy (`Inter`, `Outfit`, `Fira Code`), CSS resets, and focus ring accessibility states.

🧩

`scss/components/`

Decoupled SCSS stylesheets for navbars, buttons, metric widgets, token swatches, data tables, and modals.
