DOCUMENTATION & ARCHITECTURE FAQ

Zero-JS Accordion Panels

Click accordion headers below to expand technical answers with zero JavaScript overhead!

scss/components/_accordion.scss
ApexUI utilizes modern Dart Sass 3.0 module imports (`@use 'abstracts/variables' as *;`). The main entrypoint `scss/main.scss` aggregates all abstracts, base resets, and component stylesheets into a single minified `css/style.css` bundle via `npm run build:scss`.
The theme module `scss/abstracts/_themes.scss` defines a nested Sass map `$themes` for `dark`, `light`, and `cyber` palettes. An `@each` loop automatically emits CSS custom properties (`--bg-main`, `--brand-accent`), allowing instant theme switching with 0kb JavaScript.
Yes! All interactive elements (theme toggles, tabbed code inspectors, slide-over config drawers, fixed toast notifications, and accordion dropdowns) are implemented using native HTML5 state controls (`:target`, `:checked` input state hacks).

  'sm': 640px,

@mixin respond-to($breakpoint) {
  @if map.has-key($breakpoints, $breakpoint) {
    @media (max-width: map.get($breakpoints, $breakpoint)) {
      @content;
    }
  }
}
